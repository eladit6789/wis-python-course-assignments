# Day 01 – Academic Website

## Assignment Overview

The goal of the first assignment was to create a personal academic website using GitHub, Markdown, and Jekyll, and publish it online using GitHub Pages.

## What I Did

1. Created a GitHub repository named `eladit6789.github.io` for my academic website.
2. Created and edited the website content using Markdown in an `index.md` file.
3. Added information about my academic background, PhD research, research interests, and future plans.
4. Added links to my laboratory and scientific publications.
5. Customized the website's appearance using CSS, including a scientific banner image and styling for a more professional academic look.
6. Used Jekyll to build the website and GitHub Pages to publish it online.
7. Configured GitHub Pages to deploy the website from the `main` branch and the repository's root directory.
8. Checked that the website was published successfully and that the links and design worked as expected.

**Website:** https://eladit6789.github.io/

## What I Learned

Through this assignment, I learned the basics of GitHub repositories, Markdown, Jekyll, CSS, and GitHub Pages. I also learned how these tools work together to create and publish a website. In addition, I practiced making changes to website files, committing and synchronizing changes with GitHub, and checking the published result.
