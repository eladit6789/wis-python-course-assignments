# wis-python-course-assignments
My assignments for the Weizmann Python course.

LabProtocol includes a 24-well HBS/CaCl2 transfection workflow based on a
user-supplied laboratory example. It calculates treatment-specific DNA, pGEM,
water, 2.5 M CaCl2 and 2x HBS volumes and exports a Word protocol. The
procedure lists additions in order: DDW, automatic pGEM top-up, plasmids in
the order entered, CaCl2 and then 2x HBS. Confirm the
example's ambiguous timing and assay details before use; other vessel formats
are not supported by this example.
