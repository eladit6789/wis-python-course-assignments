# DNA Composition Calculator

## Web app

Start the Flask app from the repository root:

```text
python day04/app.py
```

Then open the [DNA composition calculator](http://127.0.0.1:5000/dna). The app must be running on your computer for this link to work.

## Command line

From the repository root, run:

```text
python day04/training/dna_composition.py
```

The script calculates nucleotide percentages for the example sequence in `sample_dna.txt`. The `calculate_percentages` function in `dna_composition.py` is also used by the web app.
